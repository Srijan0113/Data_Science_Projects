# Customer Churn Prediction (Telecom)
# Project Overview
This project focuses on predicting whether a telecom customer is likely to churn (leave the service) using machine learning classification techniques. The project is built strictly using concepts learned from Intro to Machine Learning, including model fitting, train-validation split, and Random Forest.
# Objectives
Select relevant numerical features for churn prediction
Build classification models using training data
Validate model performance on unseen data
Compare baseline model with Random Forest Classifier
# Tools & Libraries
Python 
Pandas
Scikit-learn
Jupyter Notebook
# Machine Learning Concepts Applied
Feature selection
Handling missing values
Train-validation split
Classification modeling
Model validation using accuracy
Random Forest Classifier
# Models Used
Decision Tree Classifier (Baseline Model)
Random Forest Classifier (Final Model)
# Model Evaluation
Evaluation Metric: Accuracy
Random Forest achieved higher accuracy compared to the baseline model
Validation was performed on unseen data to avoid overfitting
# Key Insights
Customers with shorter tenure are more likely to churn
Higher monthly charges increase churn probability
Random Forest provides better generalization than a single decision tree
Model validation is essential for reliable predictions
# Conclusion
This project demonstrates practical understanding of classification problems in machine learning. It applies core ML principles such as training, validation, and ensemble learning using Random Forest, following Kaggle’s beginner-level methodology.
