# Collaborative Filtering Recommender System

This project implements a User-Based Collaborative Filtering recommendation system.

---

##  Problem Statement

To recommend items to users based on the preferences of similar users.

---

##  Methodology

1. Created User-Item Interaction Matrix
2. Calculated Cosine Similarity between users
3. Identified Top-N similar users
4. Recommended items based on weighted ratings

---

##  Formula Used

Cosine Similarity:

similarity(A, B) = (A · B) / (||A|| * ||B||)

---

##  Results

- Successfully identified similar users
- Generated Top-N personalized recommendations
- Evaluated recommendations based on user ratings
