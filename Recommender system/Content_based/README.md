# Content-Based Recommender System

This project implements a Content-Based recommendation system using item features.

---

##  Problem Statement

To recommend similar items based on item characteristics.

---

##  Methodology

1. Extracted features from item dataset
2. Applied TF-IDF Vectorization
3. Computed Cosine Similarity between items
4. Generated Top-N similar item recommendations

---

##  Similarity Technique

Cosine Similarity applied on feature vectors.

---

##  Results

- Successfully recommended similar items
- Built item-to-item similarity matrix
- Generated personalized recommendations

---

##  Tools Used

- Pandas
- Scikit-learn
