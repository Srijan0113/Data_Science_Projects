# Recommender System (Collaborative + Content-Based)

This project implements two types of recommendation systems:

1. Collaborative Filtering
2. Content-Based Filtering

The goal is to build and compare different recommendation approaches using real-world datasets.

---

│   └── notebook/
│
└── README.md

---

##  1. Collaborative Filtering

- User-Item interaction matrix
- Cosine similarity
- User-based recommendation logic
- Similar users identification

---

##  2. Content-Based Filtering

- Feature extraction from item attributes
- TF-IDF / Vectorization
- Cosine similarity
- Item-to-item recommendations
