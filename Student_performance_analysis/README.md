📊 Student Performance Analysis

📌 About the Project
This project explores and analyzes student performance data using Python.  
The goal is to gain insights into academic performance trends by performing data cleaning, exploratory analysis, and visualizations.

Key tasks include:
- Loading and examining the dataset
- Handling missing values
- Visualizing distributions of scores
- Comparing performance across groups

This project showcases foundational data analysis skills using real educational data.

🛠 Tools Used  
- Python  
- Pandas  
- Matplotlib  
- Seaborn
