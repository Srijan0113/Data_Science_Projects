#  Feature Engineering

This folder contains practical implementations of important feature engineering techniques used to improve machine learning models.

Inside this folder, the following concepts have been implemented and explored:

##  Creating Features
- Built new features from existing ones.
- Created interaction features and combined variables.
- Generated derived features to capture hidden patterns.
- Applied basic transformations to improve signal strength.

##  Mutual Information (Feature Selection)
- Calculated mutual information scores between features and target.
- Ranked features based on predictive strength.
- Selected high-informative features to reduce noise.
- Compared model performance before and after feature selection.

##  Principal Component Analysis (PCA)
- Standardized data before applying PCA.
- Generated principal components from correlated features.
- Analyzed variance explained by components.
- Added selected principal components back to original features.
- Compared performance using original features, PCA-only, and combined features.

##  K-Means Clustering
- Applied unsupervised clustering to identify hidden group structures.
- Determined appropriate number of clusters.
- Added cluster labels as new features.
- Evaluated impact of clustering-based features on model performance.

---

##  Objective of This Folder

The main goal of this module is to understand how different feature engineering techniques affect model performance and to experiment with combining multiple techniques for better predictive results.
