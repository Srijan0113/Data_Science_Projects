# Classification

This folder contains all work related to **classification problems** in Machine Learning.  
It includes datasets, notebooks, scripts, and experiments used to build, train, and evaluate classification models.

---

## 📌 Objective
The main goal of this folder is to:
- Understand different **classification algorithms**
- Perform **data preprocessing & feature engineering**
- Train and evaluate models using proper metrics
- Compare model performance and improve accuracy

---

##  Algorithms Used
Some commonly used classification algorithms in this folder:
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- Naive Bayes

---

##  Evaluation Metrics
Models are evaluated using:
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- ROC-AUC (where applicable)

- Python
- NumPy
- Pandas
- Matplotlib / Seaborn
- Scikit-learn
- Jupyter Notebook
