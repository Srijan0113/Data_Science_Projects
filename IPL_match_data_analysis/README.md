## IPL Match Data Analysis

## Project Overview
This project focuses on analyzing **Indian Premier League (IPL)** match data to extract meaningful insights using **Python and Data Analysis techniques**. The analysis helps understand team performance, player impact, match outcomes, and trends across seasons.

---

## Dataset Information
The dataset contains historical IPL match and ball-by-ball data including:
- Match details (season, venue, teams)
- Toss decisions and match results
- Player of the match
- Winning margins and methods
---
## Tools & Technologies Used
- **Python**
- **Pandas** – Data manipulation & cleaning
- **NumPy** – Numerical computations
- **Matplotlib & Seaborn** – Data visualization
- **Jupyter Notebook**

---

## 🔍 Key Analysis Performed
- Total matches played per season
- Most successful teams in IPL history
- Toss impact on match results
- Venue-wise match distribution
- Top players based on awards and performance
- Win percentage of teams batting first vs chasing
