## House Price Prediction in India (Machine Learning)

## Project Overview
This project focuses on building and validating machine learning models to predict house prices in India using structured housing data. The project strictly follows concepts learned in Intro to Machine Learning such as model fitting, model validation, and Random Forests.

## Objectives
-Select relevant features for prediction
-Train machine learning models on housing data
-Validate model performance using Mean Absolute Error (MAE)
-Compare baseline model with Random Forest Regressor

## Dataset
Dataset Name: House Prices – India
Source: Kaggle
Format: CSV
Target Variable: Price
Sample Features Used
-Lot Area
-Bedrooms
-Bathrooms
-Parking
Only numerical features were selected to keep the project aligned with beginner ML concepts.

## Tools & Libraries
-Python 
-Pandas
-Scikit-learn
-Matplotlib
-Jupyter Notebook

## Machine Learning Concepts Applied
-Feature selection
-Handling missing values (mean imputation)
-Train–validation split
-Model fitting
-Model validation
-Mean Absolute Error (MAE)
-Random Forest Regressor

## Models Used
-Decision Tree Regressor (Baseline Model)
-Random Forest Regressor (Final Model)

## Key Insights
-House area is the most influential feature in price prediction
-Random Forest provides better generalization than a single decision tree
-Model validation helps avoid overfitting
-MAE gives an interpretable real-world error measure

## Conclusion
This project demonstrates a clear understanding of core machine learning principles such as training models, validating performance, and improving predictions using ensemble methods. It follows industry-standard beginner ML practices as taught by Kaggle.
