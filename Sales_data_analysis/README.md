## Sales Data Analysis (SQL + Python)
---
## Overview:
Intermediate-level project analyzing transactional sales data using SQL and Python.
---
## Dataset Columns:
order_id, order_date, region, product, quantity, unit_price
---
## Key Tasks:
-Loaded CSV data into SQLite database
-Wrote SQL queries for revenue metrics
-Analyzed:
 --Monthly sales trends
 --Top products by revenue
 --Region-wise performance
 --Visualized SQL results using Python
---
## Insights:
-Laptop is the highest revenue-generating product
-Clear upward monthly sales trend observed
-North/West regions contribute more to revenue
-Calculated Average Order Value for business understanding
---
## Tools Used:
Python, Pandas, SQLite, Matplotlib
