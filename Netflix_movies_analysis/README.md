Netflix Movies & TV Shows Data Analysis

## Project Overview

This project focuses on Exploratory Data Analysis (EDA) of Netflix Movies and TV Shows to uncover patterns related to content type, genres, release trends, and country-wise production. The analysis helps understand how Netflix’s content library has evolved over time.


---

## Objectives

-Analyze the distribution of Movies vs TV Shows

-Identify the most popular genres on Netflix

-Study year-wise growth of Netflix content

-Find top countries producing Netflix content



---

## Dataset

Dataset Name: Netflix Movies and TV Shows

Source: Kaggle

Format: CSV (netflix_titles.csv)

---

## Tools & Technologies

Python 

Pandas

NumPy

Matplotlib

Seaborn

Jupyter Notebook



---

## Data Cleaning Steps

-Handled missing values in country, director, and cast

-Converted date_added to datetime format

-Extracted year from date_added for time-based analysis

-Split and processed multi-genre data for accurate genre counts

---

## Exploratory Data Analysis

The following analyses were performed:

-Count comparison between Movies and TV Shows

-Top 10 most common genres

-Year-wise content addition trend

-Country-wise content distribution


Visualizations were created using Matplotlib and Seaborn for better insights.
