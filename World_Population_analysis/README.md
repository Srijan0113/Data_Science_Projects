# Non-Linear Regression on World Population

# Objective
To understand how to choose a non-linear regression model by visualizing data and fitting a sigmoid (logistic) curve.

# Dataset
World Population dataset (Year vs Population)
Source: https://github.com/datasets/population

# Steps Performed
--Loaded and filtered world population data.
--Visualized data to observe S-shaped growth.
--Selected sigmoid (logistic) model based on plot.
--Normalized data.
--Applied non-linear regression using curve_fit.
--Evaluated model using MAE, MSE, and R² score.

# Model Used
Sigmoid (Logistic) Function

# Tools & Libraries
--Python
--NumPy
--Pandas
--Matplotlib
--SciPy
--Scikit-learn

# Result
The sigmoid model achieved a high R² score, showing a strong fit for world population growth data.
